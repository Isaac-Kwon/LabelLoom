## v0.2.0

### New

- **LabelLoom in English, Italian and French.** The language follows your browser, and you can change it from the 파일 menu or the quick print bar. Templates are built in the chosen language, with column names and sample data to match.
- **기성 라벨 용지 tab** in the start dialog, next to 템플릿. Pick ready-made label sheets and rolls by maker and product code (Formtec, Printec AnyLabel, Avery A4/US Letter, Avery Zweckform, A-ONE, Brother DK, Lotte Express waybills, 4×6" shipping labels). Start a blank label on that stock, or open the templates sized to it. You can filter the list by the country the stock is sold in. The sizes are reference values, so do a test print and calibrate before printing a full run.
- **문의사항 (GitHub Issue)** in the 파일 menu, under 프로그램 정보, opens GitHub Issues so you can ask questions, report bugs or request features.

### Improved

- The 프린터 정렬 보정 dialog now shows which sign to enter when the print lands right/low or left/high. A scope-style diagram also shows where the print lands before correction for the X/Y offset you entered.
- Exported data now writes the print time as YYYY-MM-DD HH:mm:ss, so it reads back correctly in any language.
