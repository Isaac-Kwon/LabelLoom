## v0.1.3

### New

- **Edit tables right on the canvas.** Click a selected table (or double-click it, or press Enter) to type into its cells. Move with Enter / Tab / arrow keys, select a range with Shift, and paste straight from Excel with Ctrl+V. Drag row and column lines to resize them, and use the table toolbar or the right-click menu to insert or delete rows and columns, merge cells, make text bold and set cell colors.
- **Table layout wizard.** Drawing a table lets you choose 요일 × 교시 (with class times and lunch if you want them), 학술대회 시간표 (real clock times, with breaks and lunch spanning the whole table) or a blank table. To change an existing table's layout, use 표 형식 바꾸기… in the inspector.
- **Right-click menu on the canvas.** Right-click an object for alignment, cut / copy / paste / duplicate / delete, 맨 앞으로 / 앞으로 / 뒤로 / 맨 뒤로, group, lock, hide and more, with each shortcut shown. Right-click empty paper for 여기에 붙여넣기, 모두 선택 and 화면에 맞추기.
- **Pre-printed label stock (견출지).** A wizard builds the paper from the writable area, the frame widths, the corner radii and the spacing between labels. The printed frame appears as an on-screen guide that never prints, and objects snap to the writable area.
- **Non-printing guide objects.** Mark any object as 인쇄 안 함 (안내용) to stand in for artwork already on the stock. It shows with a dashed purple outline in the editor and is left out of print, PDF and PNG output.
- **Templates at any size.** The start dialog can now build templates for the current paper, a saved paper or a custom size. A custom size can be a single sheet or tiled across A4/Letter.
- **New template: 학술대회 명찰 (공통).** A conference badge for when every attendee gets the same design. It has no role color band and adds a footer with the date and venue.
- **Print marks.** Crop marks now show both the trim line and the bleed edge, labeled TRIM / BLEED / FOLD. You can also put color patches, a grey ramp, line-width patterns and registration targets in the paper margin, and the alignment test page prints them too.
- **링크 공유 button** in the toolbar, next to the zoom controls.

### Improved

- A share link sent without data now includes one sample row with each column's name. The receiver can see where each field goes and get a quick print preview, and no one's data ends up in the link.
- Dragging a file into the window now shows a card that lists the file types you can drop.
- Pinching on a touchpad zooms the canvas instead of the whole page, and zoom responds faster. A two-finger horizontal swipe no longer triggers browser back/forward.

### Fixed

- Ruler marks and the selection highlight on the rulers now line up with the paper (they used to be off by one ruler width).
