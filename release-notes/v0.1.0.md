## v0.1.0: First release

LabelLoom is a label and name-badge designer that runs entirely in your browser. There is no server: your designs and name lists never leave your machine. The whole app is one `index.html` file, so you can use it on GitHub Pages or download it and open it offline.

### Highlights

- **Design:** text, shapes, images, SVG, 1D barcodes (Code128, GS1-128, EAN/UPC, ITF-14, …) and 2D codes (QR, Data Matrix, Aztec, PDF417, MaxiCode). Includes snapping guides, grouping, alignment, layers and 100-step undo.
- **Paper:** A4 label sheets, badge sheets, roll labels, Letter, or a custom size. You can set up cell grids, save your own presets, add a safety margin and set a bleed.
- **Data:** import xlsx, xls or csv (CP949 is detected automatically) and bind columns with `{{column}}`. Also includes serial numbers, format tokens (`{{#seq}}`, `{{@date}}`), and per-row print flags and copy counts.
- **Event printing:** a name-list import wizard that matches Korean and English headers, conditional styles, per-row design selection, and a print history so nothing prints twice. You can reprint or register people on-site, start from any cell of a sheet, calibrate the printer and print double-sided.
- **Output:** vector browser print, PDF (vector or image), a ZIP of PNGs, and PDFs split by column value.
- **Save & share:** projects autosave in the browser. You can also save and open `.labelloom.json` files or share a design through a compressed URL link (name lists are not included by default).
