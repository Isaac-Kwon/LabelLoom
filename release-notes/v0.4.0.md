## v0.4.0

### New

- **A photo per row.** An image can name its picture with a column, such as `{{사진}}`. Add the photos as files or a ZIP (사진 추가), and each row uses the photo whose file name matches its value (the extension can be left out). The value can also be an `https://` address. Rows without a matching photo are counted in the inspector.
- **Images from a URL.** URL로 넣기… downloads a picture from the web into the project. If the server does not allow that, you can link it by address instead: it shows on screen and in print, but may be left out of PDF and PNG files and disappears if the original goes away. Web photos used by rows can be saved into the project in one go (웹 사진을 프로젝트에 저장), so they keep working offline.
- **Value filters.** Change a value right in the template: `{{이름|left:1}}`, `{{name|upper}}`, `{{직함|default:-}}`, `{{직함|prefix:(|suffix:)}}` (only when there is a value), `{{참가구분|map:연사=Speaker,좌장=Chair}}`, `{{번호|pad:4}}`, `{{금액|number}}`, `{{날짜|date:YYYY.MM.DD}}` and more. The 값 변환 list in the inspector adds one to the `{{…}}` at the cursor.
- **Mixed styles in one text box.** Make part of a text bold, italic, underlined, coloured or smaller with the 고른 글자 buttons (or tags such as `<b>…</b>`, `<color=#dc2626>…</color>`, `<size=70%>…</size>`). "**홍길동** 교수" now stays together whatever the length of the name. Text from the list is never read as tags.
- **Text on a curve.** 곡선 bends a text along an arc, upward or downward, for round stickers and seals.
- **인쇄 전 검사 (pre-print check).** The print dialog checks every label in the chosen range and lists text that runs over its box or is cut off with …, linked values that leave an object blank, code errors and missing photos. Click an entry to go to that row and object.
- **Print in groups.** 묶음 sorts the labels by a column (for example by affiliation). Each group can start on a new sheet, and a divider label with the group's name and count can go in front of it.
- **QR check-in at the desk.** In 현장 재발행 you can scan attendees' QR codes or barcodes with a USB scanner or the camera (카메라로 스캔). Choose whether a scan prints, only checks in, or both. People who were already printed are not printed again automatically. Check-in times show in the data panel and are exported with the list.
- **찾아 바꾸기 (find and replace)** (Ctrl+H) in the design text of every design, both sides and table cells, or in the data values.
- **열 다시 연결 (re-link columns).** After importing a list with different headers, point the design's `{{…}}` fields at the new columns. The data panel shows a button when the design uses columns the data doesn't have.
- **버전 기록 (version history).** Earlier states of your work are saved in the browser every 10 minutes and before other work is opened, and you can save one by hand with a name. Any of them can be restored.
- **인쇄소용 PDF (print-shop PDF).** One page per label with bleed and crop marks, with the PDF trim and bleed boxes set. It warns about vivid colours that tend to print duller in CMYK (the file itself stays RGB).
- **ZPL for label printers (experimental).** Export a `.zpl` file for Zebra-compatible label printers at 203, 300 or 600 dpi, with a black-and-white preview. This has not been tested on a real printer yet, so try one label first.

### Improved

- Browser printing waits for linked pictures to load before the print dialog opens.
