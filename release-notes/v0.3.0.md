## v0.3.0

### New

- **Tutorials.** The start dialog has a 튜토리얼 tab (shown first on your first visit) with four lessons, each with an example project: 첫 라벨 만들기, 명단으로 대량 인쇄, 바코드·QR·일련번호 and 행사 현장 운영. Opening an example keeps your current work in the recent list.
- **Guided tour.** 따라하기 시작 opens a lesson's example and walks you through it. A ring marks the button or panel each step is about and a card next to it explains what to do. Nothing covers the page, so you do each step yourself: steps like adding a text box move on once done, the rest wait for 다음, and any step can be skipped.
- **튜토리얼·도움말** in the 파일 menu (or F1) lists the lessons and their steps, with buttons to open each example and its web page. The lessons are also on the web in Korean and English.
- **Load the label list from a URL (experimental).** The import dialog takes a CSV or xlsx link; Google Sheets links work too. The source is saved in the project and can be fetched again by hand or on an interval. Rows are matched by a key column, so print checks and history are kept, and new rows are added at the end.
- **ZIP으로 저장** in the 파일 menu saves the project together with its images and fonts. Open, drag and drop and quick print accept .zip as well as .json.
- **폭에 맞추기** button in the toolbar (also in the canvas context menu, Ctrl+Shift+0) zooms the label to the canvas width and centers it.
- **View-only page on phones.** Small screens show the design one label at a time or as printed sheets, with swipe or 이전/다음 to move between them and a button to the quick print page. 그래도 편집기 열기 opens the editor anyway, and 보기 화면으로 takes you back.

### Improved

- When a share link is too long, the share dialog and quick print now say what makes it long (images, SVG graphics, the list, embedded fonts or the design itself) and what turning that option off would leave. The share dialog can also download the same content as a JSON or ZIP file.
- 행 삭제 now works with no rows picked, deleting the current row. Instead of a confirm box, the first click turns the button red (한 번 더 눌러 삭제) and the second deletes.
- Every print button now shows a notice to set scale 100%, no margins and the right paper size in the browser's print dialog, since a page can't set these itself.
- The 프린터 정렬 보정 dialog notes that a printer that feeds sheets at an angle or unevenly can still print slightly off after calibration.
