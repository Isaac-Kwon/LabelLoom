## v0.4.4

### New

- **Select rows and delete them together.** In the data table, click a row number to select it, Shift+click to select a range from the current row, and Ctrl+click (⌘+click on a Mac) to add or remove a row. Click **#** (행 선택) at the top to select every row, or every filtered row, and click it again to clear. **행 삭제** then removes the selected rows, and **선택 해제** clears the selection.
- **Delete all rows.** 더보기 › **모든 행 삭제…** empties the table and keeps its columns. While a filter is on, it becomes **필터 결과 N행 삭제…** and removes only the rows shown. You can undo it with Ctrl+Z.

### Improved

- The column mapping in 데이터 가져오기 now shows what happens to each column: **디자인에서 사용** when the design uses it, **기존 열에 합침** when it goes into an existing column with 뒤에 추가, and **새 열** otherwise. Before, every matched column was marked as linked to the design. The column list is split into columns used in the design and existing data columns.
