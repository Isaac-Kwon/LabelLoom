## v0.1.1

### New

- **Quick print:** fill in a template's fields and print, without opening the editor. Open it with `?quick`, a `#q=` link or the editor's Quick Print button. It has a live preview, prints one label at a time or a list, and has a full-screen mode and a shareable link (the link carries the design only, never the name list).
- **Table object:** for timetables and similar layouts. Supports merged cells, per-cell styles, header styling, borders and text that shrinks to fit. You can paste straight from a spreadsheet.
- **Fold duplex:** prints the front and back side by side on the same side of the sheet, so you fold them after cutting. Useful when your printer's duplex alignment is off, and for tent cards.
- **In-place editing:** double-click a text, barcode or QR object (or press Enter/F2) to edit the current row's values right on the canvas.
- **Installable app:** you can install LabelLoom as an app (PWA) and use it offline. It tells you when a new version is available.
- **Template gallery:** choose the paper size per template, and filter by paper type and label size.
- The build version and build time are shown on the page.

### Improved

- **Bleed now works end to end:** the canvas previews the bleed, and "재단 여백까지 늘리기" (extend to bleed) stretches objects into it. Bleed no longer prints onto the neighbouring label, and you get a warning when the gap between labels is too narrow.
