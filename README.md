# LabelLoom (라벨룸)

브라우저에서 라벨·명찰·바코드를 디자인하고, 엑셀/CSV 명단으로 대량 인쇄하는 **정적 웹앱**입니다.
서버가 없습니다. 모든 데이터는 사용자의 브라우저 안에서만 처리됩니다.

- 빌드 결과는 `dist/index.html` **한 파일**입니다. JS, CSS, 라이브러리가 모두 그 안에 들어 있습니다.
  GitHub Pages에 올려도 되고, 파일을 내려받아 `file://`로 열어도 똑같이 동작합니다. 인터넷 연결은 필요 없습니다.
- 작업 중인 내용은 브라우저(IndexedDB)에 자동 저장됩니다.

## 주요 기능

| 영역 | 기능 |
|---|---|
| 디자인 | 텍스트, 사각형·원·삼각형·선, 1D 바코드, QR/2D 코드, 이미지, SVG<br>이동·크기·회전 핸들, 스냅 안내선, 눈금자, 다중 선택, 그룹, 잠금·숨김, 레이어 순서(드래그)<br>정렬·분배·크기 맞춤, 개체 종류 변환, 복사·붙여넣기, 실행 취소(100단계) |
| 텍스트 | 자동 축소(최소 크기 지정), 장평 조절, 여러 줄 줄바꿈, 말줄임, 자간·행간<br>그라데이션, 그림자, 외곽선(이중) |
| 바코드 | Code128, GS1-128, Code39/93, EAN-13/8/5/2, UPC-A/E, ITF, ITF-14, Codabar, MSI, Plessey, ISBN<br>QR, GS1 QR, Data Matrix, GS1 DataMatrix, Aztec, PDF417, MaxiCode<br>QR 중앙 로고, 오류 정정 수준, 입력값 검증, 모듈 크기가 작을 때 경고 |

### 학술대회·행사 대량 인쇄

- **명단 가져오기 마법사**: 헤더를 한글·영문 동의어로 자동 연결합니다(성명·Name → 이름, Affiliation → 소속, 등록구분 → 참가구분 등). 공백을 정리하고, 중복과 빈 값을 미리 알려 줍니다.
- **조건부 스타일**: 예를 들어 `참가구분 = 연사`이면 띠를 빨간색으로, 이름이 영문이면 글자 크기를 작게 바꿉니다. 값이 비어 있는 개체는 숨길 수 있습니다.
- **디자인 자동 선택**: 한 프로젝트에 디자인을 여러 개 두고, 행의 값에 따라 출력할 디자인을 고릅니다(예: 연사 명찰과 일반 명찰).
- **출력 범위**: 인쇄 체크한 행, 아직 출력하지 않은 행, 검색·필터 결과, 행 범위, 현재 행 중에서 고릅니다. 정렬은 가나다순과 숫자 순서를 지원합니다.
- **인쇄 기록**: 행마다 출력 시각을 기록합니다. "미출력만 인쇄"로 같은 명찰을 두 번 뽑지 않게 하고, 기록은 xlsx로 내보낼 수 있습니다.
- **현장 재발행·현장 등록**: 이름으로 검색해 1장을 바로 인쇄합니다(라벨 프린터용 라벨 크기 페이지 또는 지정한 칸). 새로 온 참가자는 추가하자마자 인쇄합니다.
- **시작 칸 지정**: 일부를 이미 쓴 라벨지는 N번째 칸부터 인쇄합니다.
- **프린터 정렬 보정**: 테스트 페이지를 인쇄해 X/Y 오프셋과 배율을 맞춥니다. 재단선을 표시할 수 있습니다.
- **양면**: 뒷면 디자인을 따로 만들 수 있고, 긴 쪽 또는 짧은 쪽으로 뒤집는 배치를 고릅니다.
- **템플릿**: 학술대회 명찰(A4 2×5), 목걸이 명찰(A6), 테이블 네임텐트, 좌석·포스터 번호, QR 스티커.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 검사 후 dist/index.html 한 파일 생성
npm run preview
```

기술 스택은 Vite, React 18, TypeScript, Zustand, bwip-js(바코드), SheetJS(xlsx), jsPDF와 svg2pdf.js(PDF), JSZip입니다.
렌더링은 SVG 렌더러 하나(`src/render/svg.ts`)가 편집 화면, 인쇄, PDF, PNG 출력을 모두 담당합니다. 그래서 화면과 출력물이 같습니다.

```
src/
  model/    프로젝트 스키마(types.ts), 기본값, 용지 프리셋, 템플릿
  render/   SVG 렌더러, 텍스트 배치, 바코드, 템플릿 해석, 출력 페이지 계산
  io/       JSON 저장·IndexedDB, xlsx/csv, PDF·PNG·인쇄, URL 공유, 글꼴
  ui/       캔버스, 패널, 대화상자
```

## GitHub Pages 배포

1. GitHub에 저장소를 만들고 이 폴더를 `main` 브랜치에 푸시합니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. 이후 `main`에 푸시할 때마다 `.github/workflows/deploy.yml`이 빌드하고 배포합니다.

`vite.config.ts`의 `base`는 `/LabelLoom/`입니다 (https://isaac-kwon.github.io/LabelLoom/). 저장소 이름을 바꾸면 이 값도 바꾸세요.

## 참고

- PDF에 한글 텍스트를 벡터로 넣으려면 **파일 › 글꼴 관리**에서 TTF 글꼴을 내장하세요.
  내장하지 않은 글꼴, 굵게·기울임, 그라데이션·그림자 효과가 있는 텍스트는 지정한 해상도의 이미지로 들어갑니다.
  브라우저 인쇄는 항상 벡터로 출력됩니다.
- 공유 링크에는 기본적으로 명단 데이터가 들어가지 않습니다(개인정보 보호).
- 아직 지원하지 않는 기능: ZPL(라벨 프린터 명령어) 직접 출력.
