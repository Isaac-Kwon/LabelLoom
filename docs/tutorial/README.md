# LabelLoom 튜토리얼

[English](en/README.md)

LabelLoom(라벨룸)은 브라우저에서 라벨·명찰·바코드를 디자인하고 엑셀 명단으로 대량 인쇄하는 앱입니다.
설치할 것이 없습니다. [https://isaac-kwon.github.io/LabelLoom/](https://isaac-kwon.github.io/LabelLoom/)을 열면 바로 시작합니다.

## 앱 안에서 따라 하기

이 문서의 네 과정은 앱 안에도 그대로 들어 있습니다.

- **처음 열면** 시작 화면의 **튜토리얼** 탭이 먼저 나옵니다.
- 나중에는 **파일 › 튜토리얼·도움말** 또는 **F1**을 누릅니다.
- **따라하기 시작**을 누르면 예제 프로젝트가 열리고, 화면의 해당 버튼을 가리키며 한 단계씩 안내합니다. 직접 해 보면 다음 단계로 넘어가고, **건너뛰기**로 넘길 수도 있습니다.
- 예제를 열어도 지금 하던 작업은 시작 화면의 **최근 저장한 작업**에 남습니다.

## 과정

| | 과정 | 예제 | 배우는 것 |
|---|---|---|---|
| 1 | [첫 라벨 만들기](01-first-label.md) | 50×30 mm 빈 라벨 | 글자·도형 넣기, 속성 패널, 정렬, 용지, 인쇄 |
| 2 | [명단으로 대량 인쇄](02-mail-merge.md) | 심플 명찰 + 참가자 10명 | 엑셀 가져오기, `{{열 이름}}` 연결, 행 미리보기, 출력 범위, 인쇄 기록 |
| 3 | [바코드·QR·일련번호](03-codes.md) | 자산관리 라벨 | 바코드 종류와 경고, QR, 서식 요소, 일련번호 생성 |
| 4 | [행사 현장 운영](04-event.md) | 학술대회 명찰 (디자인 2개) | 조건부 스타일, 디자인 자동 선택, 프린터 정렬 보정, 현장 재발행, 빠른 출력 |

처음이라면 1부터 차례로 보세요. 명찰만 급하게 뽑아야 한다면 2와 4만 봐도 됩니다.

## 알아 두면 좋은 것

- **데이터는 내 브라우저 밖으로 나가지 않습니다.** 서버가 없고, 작업은 브라우저에 자동 저장됩니다. 다른 PC에서 이어 하려면 **파일 › 저장**으로 `.labelloom.json` 파일을 만드세요.
- **인쇄는 실제 크기로.** 브라우저 인쇄 창에서 배율을 100%(실제 크기)로 두세요. "페이지에 맞춤"을 켜면 라벨 칸과 어긋납니다.
- **단축키**는 `?`를 누르면 모두 볼 수 있습니다.
- 궁금한 점이나 버그는 [GitHub Issues](https://github.com/Isaac-Kwon/LabelLoom/issues)에 남겨 주세요.
