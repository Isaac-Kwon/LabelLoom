# 2. 명단으로 대량 인쇄

[← 목차](README.md) · [English](en/02-mail-merge.md) · 이전: [1. 첫 라벨 만들기](01-first-label.md) · 다음: [3. 바코드·QR·일련번호 →](03-codes.md)

엑셀 명단 한 줄이 라벨 한 장이 되게 합니다. 명찰, 주소 라벨, 수료증처럼 내용만 다른 라벨을 수백 장 뽑을 때 씁니다.

**예제 열기**: 시작 화면 **튜토리얼** 탭(또는 **F1**)에서 **명단으로 대량 인쇄 › 따라하기 시작**.
심플 명찰 디자인과 참가자 10명의 명단이 열립니다.

## 1단계 — 데이터 표 보기

화면 아래 **데이터** 표가 명단입니다.

- 첫 줄이 **열 이름**(이름, 소속, 직함…)이고, 그 아래 한 줄이 라벨 한 장입니다.
- 셀을 눌러 바로 고칩니다. **＋ 행**, **＋ 열**로 늘리고, 열 이름은 더블클릭해서 바꿉니다.
- 행마다 **인쇄 여부**(체크 상자)와 **매수**가 있습니다. 같은 사람 명찰을 2장 뽑으려면 매수를 2로 바꿉니다.

## 2단계 — 내 명단 가져오기

**가져오기 (xlsx·csv)**를 누르거나, 엑셀 파일을 화면에 그대로 끌어다 놓습니다.

- xlsx, xls, csv를 읽습니다. 한글 CSV(CP949)도 자동으로 알아봅니다.
- **첫 행은 열 이름**이어야 합니다. 병합된 셀이 있으면 경고가 나오니 원본에서 병합을 푸세요.
- **열 매핑**에서 디자인이 쓰는 열 이름과 자동으로 연결합니다. 예를 들어 `성명`, `Name`은 `이름`으로, `Affiliation`은 `소속`으로 갑니다. 틀리면 직접 바꿉니다.
- **방식**: 지금 데이터를 **바꾸기**, 또는 **뒤에 추가**.

## 3단계 — `{{열 이름}}` 연결

캔버스에서 이름 글상자를 고르고 속성 패널의 **내용 · 데이터 연결**을 봅니다.

- 내용이 `{{이름}}`입니다. 중괄호 두 쌍으로 감싼 열 이름은 인쇄할 때 그 행의 값으로 바뀝니다.
- 글자와 섞어 써도 됩니다: `{{이름}} 님`, `{{소속}} · {{직함}}`.
- 옆의 열 목록에서 고르면 커서 자리에 `{{열 이름}}`이 들어갑니다.
- 아래 회색 칸에 **현재 행으로 계산된 값**이 보입니다.
- 값이 빈 행에서 글상자를 아예 감추려면 **값이 비면 숨김**을 켭니다(예제의 직함 글상자).

레이어 목록에서 ⛓ 표시가 붙은 개체가 데이터와 연결된 개체입니다.

## 4단계 — 행 넘겨 보기

캔버스 위 **미리보기 ◀ ▶** 또는 `PageUp`/`PageDown`으로 다른 사람의 명찰을 봅니다.
데이터 표에서 행을 클릭해도 그 행이 미리보기에 나옵니다.

긴 이름은 **자동 축소** 덕분에 상자 안에 들어갑니다. 너무 작아지면 상자를 넓히거나 최소 크기를 조절하세요.

## 5단계 — 출력 범위 고르기

**인쇄 · 내보내기**를 열고 **대상**을 고릅니다.

| 대상 | 쓰는 때 |
|---|---|
| 인쇄 체크된 행 | 기본값. 체크를 해제한 행은 빠집니다 |
| 아직 출력 안 한 행 | 추가 등록자만 이어서 뽑을 때 |
| 현재 필터 결과 | 데이터 표에서 검색·필터한 사람만 |
| 행 범위 | 1~40행처럼 나눠서 뽑을 때 |
| 현재 행만 | 한 장만 다시 뽑을 때 |

이미 몇 칸을 쓴 라벨지는 **시작 칸**에서 남은 첫 칸을 클릭하면 그 칸부터 인쇄합니다.

## 6단계 — 인쇄 기록

인쇄하거나 내보내면 행마다 **출력** 열에 시각이 남습니다.

- 다음에 **아직 출력 안 한 행**을 고르면 같은 명찰을 두 번 뽑지 않습니다.
- 출력 칸을 클릭하면 기록을 직접 켜고 끌 수 있습니다. 모두 지우려면 **더보기 › 인쇄 기록 지우기**.
- 데이터 막대의 **내보내기 › xlsx (인쇄 기록 포함)**으로 누가 언제 출력됐는지 받아 둡니다.

## 더 알아보기

- **중복 검사**: **더보기 › 중복 검사…**에서 이름·이메일이 겹치는 행을 표시합니다.
- **URL에서 불러오기**(실험적): 가져오기 창에 CSV나 Google 스프레드시트 주소를 넣으면 주기적으로 다시 받아 새 행을 추가합니다.
