# 1. 첫 라벨 만들기

[← 목차](README.md) · [English](en/01-first-label.md) · 다음: [2. 명단으로 대량 인쇄 →](02-mail-merge.md)

50×30 mm 빈 라벨에 글자와 도형을 넣고, 모양을 다듬고, 인쇄까지 합니다. 10분이면 됩니다.

**예제 열기**: 시작 화면 **튜토리얼** 탭(또는 **F1**)에서 **첫 라벨 만들기 › 따라하기 시작**.
라벨 위의 회색 글자는 **인쇄되지 않는 안내 개체**입니다. 레이어 목록에 ⊘ 표시가 붙어 있습니다.

## 화면 둘러보기

| 위치 | 이름 | 하는 일 |
|---|---|---|
| 맨 위 | 도구 막대 | 파일 메뉴, 실행 취소, 개체 도구(텍스트·사각형·바코드…), 확대, **인쇄 · 내보내기** |
| 왼쪽 | 레이어 · 용지 · 디자인 탭 | 개체 목록과 순서, 용지 크기와 칸 나누기, 디자인 여러 개 |
| 가운데 | 캔버스 | 라벨을 직접 그리고 옮기는 곳 |
| 오른쪽 | 속성 패널 | 고른 개체의 내용, 글꼴, 색, 위치·크기 |
| 아래 | 데이터 | 명단 표 (2장에서 다룹니다) |

## 1단계 — 글상자 넣기

1. 도구 막대에서 **텍스트**(단축키 `T`)를 누릅니다.
2. 라벨 위를 클릭하면 기본 크기의 글상자가, 끌면 끈 크기만큼의 글상자가 생깁니다.
3. 개체를 하나 넣으면 도구는 다시 **선택**(`V`)으로 돌아갑니다.

## 2단계 — 속성 패널에서 다듬기

글상자를 고른 채로 오른쪽 속성 패널을 봅니다.

- **내용 · 데이터 연결**: 글자를 고칩니다. 캔버스에서 글상자를 **더블클릭**해도 바로 고칠 수 있습니다.
- **텍스트**: 글꼴, 크기(pt), 굵게, 정렬, 줄바꿈, 자간·행간.
  기본으로 **자동 축소**가 켜져 있어서, 글자가 상자보다 길면 **최소** 크기까지 저절로 작아집니다.
- **위치·크기 (mm)**: 숫자로 정확히 맞춥니다.

## 3단계 — 도형 넣기

1. **사각형**(`R`)이나 **선**(`L`)을 골라 라벨 위에서 끌어 그립니다.
2. 끌어서 옮기고, 모서리 핸들로 크기를 바꾸고, 회전 핸들로 돌립니다.
   `Shift`를 누른 채 끌면 수평·수직으로만 움직이고, `Alt`를 누르면 스냅이 꺼집니다.
3. 도형 뒤에 글자가 가려지면 왼쪽 **레이어** 목록에서 순서를 끌어 바꾸거나, 개체를 오른쪽 클릭해 **맨 뒤로**를 고릅니다.

## 4단계 — 여러 개를 맞추기

- `Shift`+클릭으로 개체를 여러 개 고르면 속성 패널 맨 위에 **정렬**(왼쪽·가운데·오른쪽, 위·가운데·아래)과 **분배**, **폭·높이 맞춤** 버튼이 나옵니다.
- 방향키는 0.5 mm, `Shift`+방향키는 5 mm씩 옮깁니다.
- `Ctrl+G`로 묶으면 함께 움직입니다.

## 5단계 — 저장과 실행 취소

- 실수하면 **실행 취소**(`Ctrl+Z`). 100단계까지 되돌릴 수 있습니다.
- 작업은 브라우저에 **자동 저장**됩니다. 창을 닫았다 열어도 그대로입니다.
- 파일로 남기려면 **파일 › 저장**(`Ctrl+S`). `.labelloom.json` 파일이 생기고, **파일 › 열기**나 화면에 끌어다 놓기로 다시 엽니다.

## 6단계 — 용지 정하기

왼쪽 **용지** 탭에서 라벨 한 칸의 크기, 한 장에 들어가는 칸 수(가로×세로), 여백과 간격을 정합니다.

- 시판 라벨지(폼텍, Avery 등)는 **파일 › 새로 만들기 · 템플릿 › 기성 라벨 용지** 탭에서 제품 번호로 고릅니다.
- 자주 쓰는 용지는 **내 프리셋**으로 저장해 둡니다.

## 7단계 — 인쇄

1. **인쇄 · 내보내기**(`Ctrl+P`)를 누릅니다.
2. **형식**을 고릅니다.
   - **인쇄**: 브라우저 인쇄. 벡터로 깨끗하게 나오고, 인쇄 창에서 "PDF로 저장"도 됩니다.
   - **PDF**: 파일로 받습니다. 한글을 벡터로 넣으려면 **파일 › 글꼴 관리**에서 TTF 글꼴을 내장하세요.
   - **PNG (ZIP)**: 라벨 하나하나를 그림으로 받습니다.
3. 브라우저 인쇄 창에서는 **배율 100%(실제 크기)**, 여백 "없음" 또는 "기본"으로 두세요.

회색 안내 글자처럼 **인쇄 안 함 (안내용)**에 체크한 개체는 화면에만 보이고 인쇄되지 않습니다.
