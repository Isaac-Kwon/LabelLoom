# 3. 바코드·QR·일련번호

[← 목차](README.md) · [English](en/03-codes.md) · 이전: [2. 명단으로 대량 인쇄](02-mail-merge.md) · 다음: [4. 행사 현장 운영 →](04-event.md)

바코드와 QR 코드를 넣고, 라벨마다 다른 번호와 날짜가 찍히게 합니다.

**예제 열기**: 시작 화면 **튜토리얼** 탭(또는 **F1**)에서 **바코드·QR·일련번호 › 따라하기 시작**.
자산관리 라벨과 자산 12개 목록이 열립니다. 바코드와 QR이 모두 `{{자산번호}}`를 담고 있습니다.

## 1단계 — 바코드 종류 고르기

캔버스에서 바코드를 고르고 속성 패널의 **바코드** 칸을 봅니다.

- **종류**: 쓰는 곳에 맞는 규격을 고릅니다.

  | 규격 | 주로 쓰는 곳 |
  |---|---|
  | Code128 | 사내 관리 번호, 송장. 영문·숫자 아무거나 (기본값) |
  | EAN-13 / UPC-A | 상품 바코드. 숫자 12~13자리 |
  | GS1-128 | 유통기한·로트가 들어가는 물류 라벨 |
  | Code39, ITF, Codabar … | 기존 장비가 그 규격만 읽을 때 |

- 값이 규격에 맞지 않으면(EAN-13에 글자가 있다든지) 경고가 나오고, 그 코드는 인쇄할 때 빈칸이 됩니다.
- 라벨이 작아 막대가 너무 가늘면 스캐너가 못 읽을 수 있다는 경고가 나옵니다. 바코드를 넓히거나 값을 줄이세요.
- **문자 표시**로 바코드 아래 숫자를 켜고 끕니다.

## 2단계 — QR 코드 넣기

1. 도구 막대에서 **QR 코드**(`Q`)를 고르고 라벨의 빈 곳에 넣습니다.
2. **QR / 2D 코드** 칸에서 종류(QR, Data Matrix, PDF417 …)와 **오류 정정** 수준을 고릅니다.
   가운데에 **로고**를 넣는다면 오류 정정을 Q나 H로 올리세요.
3. 내용에는 URL, 연락처, Wi‑Fi 정보, `{{열 이름}}` 무엇이든 넣을 수 있습니다.

## 3단계 — 서식 요소

내용 칸 옆 **서식 요소** 목록에서 고르면 인쇄할 때 계산되는 값이 들어갑니다.

| 서식 요소 | 결과 |
|---|---|
| `{{#seq}}` | 인쇄 순서대로 1, 2, 3 … (시작 번호는 **디자인** 탭의 **일련번호**에서) |
| `{{#seq:0000}}` | 0001, 0002 … 처럼 자릿수를 채운 번호 |
| `{{#row}}` | 데이터 행 번호 |
| `{{@date:YYYY-MM-DD}}` | 인쇄하는 날의 날짜. `YYYY.MM.DD`, `YY/MM/DD`처럼 형식을 바꿀 수 있습니다 |
| `{{@time:HH:mm}}` | 인쇄하는 시각 |
| `{{^GS}}` | GS1 바코드의 구분 문자 |

예: 바코드 내용을 `IT-{{#seq:0000}}`으로 두면 IT-0001, IT-0002 … 가 차례로 찍힙니다.

## 4단계 — 일련번호 열 만들기

명단이 없어도 번호가 매겨진 라벨을 만들 수 있습니다.

1. 데이터 막대에서 **일련번호 생성**을 누릅니다.
2. **열 이름**, **시작**, **증감**, **자릿수**, **개수**, **접두**·접미를 정합니다.
   예: 접두 `A-`, 시작 1, 자릿수 3, 개수 100 → A-001 … A-100
3. **적용**하면 데이터 표에 번호 열이 생깁니다.
4. 바코드나 글상자 내용에 `{{그 열 이름}}`을 넣으면 라벨마다 다른 번호가 나옵니다.

`{{#seq}}`와의 차이: 일련번호 **열**은 표에 값이 남아 있어서 엑셀로 내보내거나 특정 번호만 다시 뽑기 좋습니다. `{{#seq}}`는 표 없이 인쇄 순서대로 매겨집니다.
