# 4. 행사 현장 운영

[← 목차](README.md) · [English](en/04-event.md) · 이전: [3. 바코드·QR·일련번호](03-codes.md)

학술대회나 행사에서 명찰을 준비하고 현장에서 다시 뽑는 흐름입니다. 2장(명단으로 대량 인쇄)을 먼저 보면 이해가 쉽습니다.

**예제 열기**: 시작 화면 **튜토리얼** 탭(또는 **F1**)에서 **행사 현장 운영 › 따라하기 시작**.
학술대회 명찰과 참가자 10명이 열립니다. 디자인이 **일반 명찰**과 **연사 명찰** 두 개입니다.

## 1단계 — 조건부 스타일

명찰 위·아래의 색 띠를 고르고 속성 패널 맨 아래 **조건부 스타일**을 엽니다.

- 규칙 하나는 "**참가구분** 열이 **연사**와 같으면 → 색을 빨강으로"처럼 생겼습니다.
- 조건: 같음, 다름, 포함, 비어 있음, 값 있음, 한글 포함, 영문, 글자 수.
- 바꿀 수 있는 것: 색, 글자 크기, 내용, 숨김.
- **＋**로 규칙을 더합니다. 위에서부터 차례로 적용됩니다.

예제에는 연사·좌장·학생·스태프마다 띠 색이 다르게 들어 있고, 이름 글상자에는 "영문이면 글자 크기 20"이라는 규칙이 있습니다.
레이어 목록에서 ◆ 표시가 붙은 개체가 규칙을 가진 개체입니다.

## 2단계 — 행 넘겨 보며 확인

캔버스 위 **◀ ▶**로 행을 넘깁니다. 참가구분에 따라 띠 색이 바뀌고, 연사 행에서는 "→ 이 행은 "연사 명찰"" 표시가 나옵니다.

## 3단계 — 디자인 자동 선택

왼쪽 **디자인** 탭을 엽니다.

- 한 프로젝트에 디자인을 여러 개 둘 수 있습니다. 맨 위가 **기본** 디자인입니다.
- **디자인 자동 선택 규칙**: "참가구분 = 연사 → 연사 명찰". 규칙에 맞지 않는 행은 기본 디자인으로 나옵니다.
- 인쇄하면 행마다 맞는 디자인이 골라져 한 번에 섞여 나옵니다.

조건부 스타일로 색만 바꾸면 충분할 때는 디자인 하나로, 배치 자체가 달라야 할 때(연사에게 사진이나 강연 제목을 넣는 등)는 디자인을 나눕니다.

## 4단계 — 프린터 정렬 보정 (행사 전에 한 번)

프린터마다 인쇄 위치가 1~2 mm씩 어긋납니다. 라벨지에 뽑기 전에 맞춰 두세요.

1. **파일 › 프린터 정렬 보정…**을 엽니다.
2. **정렬 테스트 페이지**를 일반 종이에 인쇄해 라벨지와 겹쳐 보거나 자로 잽니다.
3. 오른쪽/아래로 밀려 나오면 **음수**, 왼쪽/위로 치우치면 **양수**를 X/Y 이동에 넣습니다. 50 mm 눈금이 실제와 다르면 배율을 고칩니다.
4. 보정값은 프로젝트에 저장되고 인쇄·PDF에 적용됩니다.

## 5단계 — 현장 재발행 · 현장 등록

도구 막대의 **현장 재발행**을 엽니다.

- **재발행**: 이름·소속·ID로 검색해 **인쇄**를 누르면 그 사람 명찰 1장만 바로 나옵니다.
  출력 방식은 라벨 프린터용 **라벨 크기 1장**, 또는 라벨지의 **N번째 칸** 중에서 고릅니다.
- **현장 등록**: 명단에 없는 사람은 아래 칸에 값을 넣고 **등록하고 인쇄**를 누릅니다. 명단에 추가되고 바로 인쇄됩니다.
- 인쇄한 행은 출력 기록이 남아서, 나중에 **아직 출력 안 한 행**으로 뽑을 때 빠집니다.

## 6단계 — 빠른 출력

**빠른 출력**은 편집기 없이 **값 입력 → 미리보기 → 인쇄**만 하는 화면입니다.

- 입력 칸은 디자인의 `{{열 이름}}`에서 자동으로 만들어집니다.
- 1건씩 바로 인쇄하거나, **목록에 추가**해 모았다가 한 번에 인쇄합니다.
- 접수대 PC에 이 화면만 띄워 두면 디자인을 실수로 건드릴 일이 없습니다.
- 주소 끝에 `?quick`을 붙여 열면(예: `https://isaac-kwon.github.io/LabelLoom/?quick`) 처음부터 빠른 출력 화면이 나옵니다. 저장해 둔 `.labelloom.json` 템플릿을 그 화면에서 엽니다.

## 명단을 붙여넣어 가져오기

명단은 파일 대신 클립보드로도 가져올 수 있습니다. 엑셀·Google 스프레드시트에서 열 이름 행까지 범위를 복사하거나 학회 관리 사이트의 복사 버튼을 누른 뒤, **가져오기 (xlsx·csv)** 창에서 **Ctrl+V**(Mac은 **⌘V**)를 누르거나 **클립보드에서 붙여넣기**를 누릅니다. 버튼을 누르면 브라우저가 클립보드 읽기 권한을 물을 수 있는데, 허용하지 않았거나 `index.html`을 파일로 열었다면 Ctrl+V를 쓰면 됩니다. 붙여넣은 내용은 브라우저 안에서만 읽고 어디로도 보내지 않습니다. 탭이나 쉼표로 나뉜 텍스트가 표로 읽히고, 파일과 같은 열 매핑 화면이 나옵니다. 명단이 바뀌어 다시 붙여넣을 때는 **뒤에 추가**를 고르고 **키 열**(기본은 ID)을 두면, 이미 있는 사람은 값만 바뀌고(인쇄 체크·출력 기록은 그대로) 새로 등록한 사람만 뒤에 붙습니다. 붙여넣은 데이터는 URL처럼 자동으로 새로고침되지 않습니다.

## 행사 당일 체크리스트

- [ ] 명단 최종본을 가져오고 **더보기 › 중복 검사…**
- [ ] 프린터 정렬 보정, 테스트 1장
- [ ] **인쇄 · 내보내기 › 대상: 인쇄 체크된 행**으로 일괄 인쇄
- [ ] 현장에서는 **현장 재발행**, 마감 후 **아직 출력 안 한 행**으로 남은 것 인쇄
- [ ] 끝나면 **파일 › 저장**, 데이터 **내보내기 › xlsx (인쇄 기록 포함)**으로 기록 보관
