# 기성 라벨 용지 사양서 (시트 · 롤 · 테이프)

LabelLoom 용지 프리셋을 만들기 위한 참고 자료다. 구현을 맡은 사람(또는 AI)이 이 문서와
[label-stock-specs.json](label-stock-specs.json)만 보고 프리셋·검증 로직을 만들 수 있게 썼다.

- 기준일: 2026-10-24. 단위는 전부 **mm**.
- 한국 제품(폼텍, 프린텍 애니라벨, 국내 롤라벨·라벨 프린터)이 주 대상이고, 해외 제품은 국내에서도 많이 쓰거나
  해외 사용자가 찾을 만한 것(Avery A4/US Letter, Avery Zweckform, A-ONE, Brother, DYMO, Niimbot)만 넣었다.
- 시트 라벨 수치는 사람이 옮겨 적지 않았다. 제조사가 배포한 Word 서식과 Word 내장 라벨 DB에서 스크립트로 뽑았다(§9).
- 롤·테이프 수치 중 일부는 판매 페이지 표기라 확인 수준을 같이 적었다. "미확인"은 하드코딩하지 말고 사용자 입력으로 받는다.

## 1. 용어와 좌표계

```
  ┌───────────────────────── page.w ─────────────────────────┐
  │        ↑ top                                             │
  │ left ┌──────────┐ gapX ┌──────────┐                       │
  │ ───→ │ label    │ ←──→ │          │   …  right            │
  │      │ w × h    │      │          │                       │
  │      └──────────┘      └──────────┘                       │
  │        ↕ gapY                                            │
  │      ├─ pitchX ─┤ = label.w + gapX                        │
  └──────────────────────────────────────────────────────────┘
```

| 항목 | 정의 | `Paper` 필드 ([src/model/types.ts](../src/model/types.ts)) |
|---|---|---|
| page.w × page.h | 용지(시트) 크기. A4 = 210×297, US Letter = 215.9×279.4 | `width`, `height` |
| label.w × label.h | 라벨 한 칸 크기(다이컷 외곽) | `labelWidth`, `labelHeight` |
| cols × rows | 열 수 × 행 수 | `cols`, `rows` |
| left / top | 용지 좌상단 → **첫 라벨(1열 1행) 좌상단** 거리 | `marginLeft`, `marginTop` |
| pitchX / pitchY | 이웃 라벨의 좌상단끼리 거리 | (= label + gap) |
| gapX / gapY | 라벨과 라벨 사이 빈 간격 = pitch − label | `gapX`, `gapY` |
| right / bottom | 마지막 라벨 바깥쪽에서 용지 끝까지. 검증용 파생값 | – |
| cornerRadius | 모서리 반경. 원형이면 w/2 | `cornerRadius` |
| holeDiameter | CD 라벨 가운데 구멍 지름 | **현재 모델에 없음** (§8) |

- 원점은 용지 좌상단, x는 오른쪽, y는 아래로 증가한다.
- 라벨 번호는 행 우선(왼→오, 위→아래)이 국내외 제조사 공통이다.
- `pitch` 대신 `gap`을 저장하면 Word가 0.01 mm 단위로 반올림한 값이 행·열마다 누적된다. 이 문서의 값은 Word 반올림을 정리했으므로
  `gap = pitch − label` 그대로 넣으면 된다.

## 2. 공차와 구현 원칙 (꼭 읽을 것)

실제 출력은 "라벨 위치 오차 + 프린터 급지 오차 + 배율 오차"가 겹친다. 프리셋 수치가 정확해도 출력이 1~2 mm 어긋나는 것은 정상이다.

| 요인 | 크기(일반값) | 설명 |
|---|---|---|
| 다이컷 위치 (시트) | ±0.5 mm | 칼선 금형·인쇄 공정 공차. 제조사 사이에도 같은 "규격"이 0.3~1 mm 다르다(아래 표의 "제조사 서식값" 참고) |
| 시트 급지 (레이저/잉크젯) | ±1.0~2.0 mm (상하가 더 큼) | 급지 롤러 미끄러짐·용지 휨. 수동 급지대가 더 나쁘다 |
| 배율 (시트) | ±0.3~0.5 % | 297 mm 기준 최대 약 1.5 mm. "용지에 맞춤" 인쇄 옵션이 켜지면 수 % 줄어든다 |
| 프린터 비인쇄 영역 | 가장자리 3~5 mm | 레이저 대부분 4~5 mm, 잉크젯 3 mm 안팎. 가장자리 무여백 라벨(Zweckform 3474 등)은 바깥 라벨 끝이 잘린다 |
| 롤 피드 방향 위치 (감열) | ±0.5~1.0 mm | 갭/블랙마크 센서 기준. 첫 장은 더 클 수 있음 |
| 롤 가로 위치 (감열) | ±0.5~1.0 mm | 라이너 가이드 유격. 라이너 폭 = 라벨 폭 + 2~4 mm |
| Word 서식 반올림 | ≤0.05 mm | twip(0.0176 mm) 단위. 무시해도 됨 |

구현 원칙:

1. **보정 기능 필수.** 이미 있는 `Calibration { offsetX, offsetY, scaleX, scaleY }`를 프린터별로 저장해 쓰게 한다. 프리셋을 아무리 맞춰도 프린터마다 1~2 mm 차이는 남는다.
2. **안전 여백(safeMargin) 기본값.** 시트 1.5 mm, 롤 1.0 mm, 높이 15 mm 미만 소형 라벨 0.8~1.0 mm. 배경·테두리를 라벨 끝까지 칠하는 디자인에는 "1 mm 어긋남 시 흰 줄이 보일 수 있음" 경고를 띄운다.
3. **간격 0(맞붙은 칼선) 라벨**은 오차가 이웃 칸으로 넘어간다. 가장자리 꽉 찬 배경은 피하도록 안내한다.
4. **가장자리 3 mm 이내 라벨**이 있는 용지(아래 표 비고에 표시)는 "프린터에 따라 끝이 잘림" 경고를 띄운다.
5. **인쇄 대화상자 "실제 크기(100%)" 안내.** 브라우저 인쇄는 기본으로 "맞춤"이 켜질 수 있다. 출력 화면에 안내 문구를 둔다.
6. 같은 규격이라도 제조사별로 0.3~1 mm 다르므로 "규격명(63.5×38.1 21칸)"보다 **제조사+코드**로 고르게 하고, 동등 규격은 검색 별칭으로 묶는다(JSON `equivalents`).
7. 롤·감열 프린터는 해상도에 맞춰 스냅한다. 203 dpi = 8 dot/mm, 300 dpi = 11.81 dot/mm. 바코드 모듈 폭은 정수 dot이어야 판독률이 유지된다.

## 3. 출처와 신뢰도

| 표기 | 출처 | 신뢰 |
|---|---|---|
| Word | Microsoft Word 내장 라벨 DB. 라벨 제조사가 MS에 등록한 정의로, 사용자가 Word "편지 > 레이블"에서 쓰는 값과 같다 | high |
| 서식 | 제조사 홈페이지가 제품별로 배포하는 Word 서식(.doc)에서 페이지 여백과 표 셀 크기를 읽은 값 | medium |
| 카탈로그/판매처 | 제조사 카탈로그 PDF, 판매 페이지 | 크기는 high, 배치 정보 없음 |

- 서식 파일은 셀 폭이 "라벨+간격"(= 피치)인 경우가 많다. 이때 라벨은 셀의 왼쪽 위에 맞춘다고 보고 계산했다. Avery L7163과 비교하면 이 방식의 좌측 오차는 0.05 mm 이내였다.
- 같은 코드에서 Word 값과 서식 값이 0.3 mm 넘게 다르면 Word 값을 기본으로 하고, 서식 값은 비고(JSON `alternatives`)에 남겼다. 1 mm 넘게 다르면 신뢰도를 medium으로 낮췄다.
- 폼텍은 Word 내장 DB에 없어서 폼텍 서식 값만 있다.
- 비고의 "상하 여백(상/하)"은 오류 표시가 아니라 참고 정보다. 국내 시트는 위 여백이 아래보다 작은 경우가 많고, 같은 규격의 폼텍 서식과 프린텍 Word 값이 일치하는 경우가 많아(3189 = V3560 = 11.99/15.01, 3136 ≈ V3590, 3154 = V3540) 실제 칼선으로 본다.
- 확인이 필요한 경우: 같은 규격인데 제조사 간 위치가 1 mm 넘게 다른 것. 대표적으로 99.1×38.1 14칸의 상단이 폼텍 3108 13.79, Avery L7163 15.13, 프린텍 V3230 15.87로 2 mm 차이 난다. 각 제조사 값을 그대로 쓰되 **실측 1회 권장.**
- 모서리 반경은 어느 출처에도 수치가 없다. JSON의 사각 라벨 `cornerRadius`는 `null`이다. 기본값 정책: 간격이 있는 시트 라벨 R 1.5(제조사 가이드 이미지상 둥근 모서리), 간격 0인 라벨 R 0, 롤 라벨 R 1.5. 반경은 화면 외곽선과 안전영역 표시에만 쓰이고 인쇄 위치에는 영향이 없다.

### 3.1 제조사별 사용 국가

앱의 "기성 라벨 용지" 탭 국가 필터가 쓰는 값이다([src/model/stock.ts](../src/model/stock.ts) `sheetCountries`). 판매 지역 기준이며, 기본 필터는 UI 언어로 정한다(한국어 → 한국, 이탈리아어 → 이탈리아, 프랑스어 → 프랑스, 영어 → 전체).

| 제조사 · 제품군 | 국가 | 비고 |
|---|---|---|
| 폼텍, 프린텍 애니라벨 (시트·롤), 롯데택배 운송장 | KR | |
| Avery US Letter (5160 등) | US, CA | Letter 용지 |
| Avery A4 L/J 시리즈 (L7160 등) | GB, IE, FR, IT, ES, DE | Avery 유럽 공통 제품군. 프랑스·이탈리아도 같은 코드로 판매 |
| Avery Zweckform 고유 코드 (3474, 3490 등) | DE, AT, CH | 독일어권. 70×37 등 무여백 규격 |
| A-ONE | JP | |
| Brother DK, 4×6" 배송 라벨 | 전 세계 | 모든 국가 필터에 나옴 |

이탈리아·프랑스 현지 브랜드(Tico, Agipa, Apli 등)는 아직 넣지 않았다. 규격 자료를 확인하지 못했기 때문이다. 크기와 칸 수가 같은 Avery A4 프리셋이 있으면 그것으로 시작하고 시험 출력으로 맞춘다.

## 5. 한국 롤 라벨 · 라벨 프린터

롤 라벨은 "용지 = 라벨 한 장"으로 다룬다(현재 `roll()` 프리셋 방식). 시트와 달리 다음 값이 추가로 필요하다.

| 항목 | 설명 | 일반값 |
|---|---|---|
| 라벨 W×H | W = 프린터 헤드 방향(롤 폭 방향), H = 피드 방향 | – |
| 갭(gap) | 라벨 사이 라이너만 있는 구간. 프린터 갭 센서가 읽는다 | 2~3 mm (국내 감열 롤 대부분 2 또는 3) |
| 라이너 폭 | 라벨 폭 + 좌우 여유 | 라벨 폭 + 2~4 mm |
| 지관(코어) 내경 | 프린터 롤 홀더와 맞아야 함 | 25.4 mm(1"), 38~40 mm(1.5"), 76.2 mm(3", 산업용) |
| 감지 방식 | 갭 / 블랙마크 / 연속지 | 갭이 대부분 |
| 인쇄 방식 | 감열(Direct Thermal, 리본 없음) / 열전사(Thermal Transfer, 리본) | 아트지·필름은 열전사 |
| 해상도 | 헤드 해상도 | 203 dpi(8 dot/mm), 300 dpi(11.81 dot/mm) |
| 인쇄 가능 폭 | 헤드 폭. 라벨이 더 넓으면 잘린다 | 2" 48 mm(384 dot), 3" 72 mm(576 dot), 4" 104 mm(832 dot @203) |
| 출력 방향 | 프린터 드라이버 기준 W/H가 바뀌어 보일 수 있음 | 라벨 W > 헤드 폭이면 회전 필요 |

## 7. 라벨 모양 정의

| 모양 | 정의 | 현재 모델로 표현 | 비고 |
|---|---|---|---|
| 사각 | w×h, R 0 | `cornerRadius: 0` | 간격 0 라벨, 일부 인덱스 라벨 |
| 둥근 사각 | w×h, R > 0 | `cornerRadius: R` | 대부분의 시트·롤 라벨. R 1.5~3 (수치 미공개, 기본 1.5) |
| 원형 | 지름 d, w = h = d | `cornerRadius: d/2` | 폼텍 3639·3640·3641, 프린텍 V3630·V3760·V385x, Avery L7780·L7670 |
| 타원 | w ≠ h, 완전 둥근 끝 | 지원 안 됨 | 국내 기성품 거의 없음. 필요하면 `shape: 'ellipse'` 추가 |
| CD/DVD | 외경 D + 내경 구멍 d | 지원 안 됨 (원형 + 구멍) | 폼텍 3642P(Ø117.8/Ø41), 3642AP(Ø117.8/Ø17.5), 프린텍 V3771(Ø118/Ø41), Avery L7676(Ø117/Ø41) |
| 케이블(깃발형) | 인쇄부 + 감는 꼬리 | 지원 안 됨 | Niimbot 케이블 라벨 등. 인쇄부만 라벨로 두고 꼬리는 무시해도 실용상 충분 |

## 8. 구현 제안

### 8.1 데이터 모델 보강

현재 `Paper`로 대부분 표현되지만, 아래가 있으면 프리셋 품질이 올라간다.

```ts
interface StockMeta {            // Paper에 선택 필드로 붙이거나 프리셋 목록에만 둔다
  vendor?: string;               // 'Formtec' | 'Printec' | 'Avery' | ...
  code?: string;                 // '3108', 'V3230', 'L7163'
  aliases?: string[];            // 동일 규격: ['Printec V3230', 'Avery L7163'] — 검색용
  shape?: 'rect' | 'circle' | 'ellipse' | 'cd';
  holeDiameter?: number;         // CD 내경
  confidence?: 'high' | 'medium' | 'low';
  roll?: {
    gap: number;                 // 라벨 사이 간격 (피드 방향)
    linerWidth?: number;
    coreInner?: number;          // 지관 내경
    sensing?: 'gap' | 'blackmark' | 'continuous';
    method?: 'direct-thermal' | 'thermal-transfer';
    dpi?: 203 | 300 | 180 | 360;
    printableWidth?: number;     // 헤드 폭 (또는 기종별 인쇄 가능 폭)
    feedDirection?: 'top' | 'left'; // Niimbot D11 계열 'left'
    continuous?: boolean;        // P-touch, DK 연속 롤
  };
}
```

### 8.2 현재 프리셋과 비교 ([src/model/presets.ts](../src/model/presets.ts))

현재 시트 프리셋은 `sheet()`가 그리드를 용지 중앙에 두는 방식이다. 대부분 Avery 칼선과 0.1 mm 안쪽으로 맞지만 아래는 차이가 크다.

| 현재 프리셋 | 문제 | 제안 |
|---|---|---|
| `A4 원형 4×6 (Ø40)` 간격 7 | 실제 국내·Avery 제품(V3630, L7780)은 피치 46 (간격 **6**), 좌 16 / 상 13.49. 간격 7이면 마지막 행이 약 3 mm 어긋남 | 간격 6으로 수정하고 V3630 데이터로 교체 |
| `A4 원형 3×4 (Ø60)` | 국내 기성품은 Ø63(폼텍 3640, 피치 67×67.67) 또는 Ø63.5(V3760, 피치 67.7). Ø60 3×4 제품은 찾지 못함(A-ONE 28396은 60×60 사각) | Ø63/Ø63.5 프리셋 추가, Ø60은 "사용자 정의 예시"로만 남김 |
| `A4 3×7 (63.5×38.1)` 간격 2.5 | 중앙 배치 결과(7.25/15.15)가 Avery L7160(7.2/15.13)과 일치. 폼텍 3105(7.2/15.79), 프린텍 V3330(7.62/15.87)과는 0.4~0.7 mm 차 | 제조사별 프리셋을 따로 두고, 이 프리셋은 "일반(Avery L7160 호환)"으로 이름 변경 |
| `A4 4×10 (48.5×25.4)` 간격 0 | Zweckform 3657/4780과 일치. 국내 제품은 아님 | 그룹을 "해외"로 옮기거나 이름에 Zweckform 3657 표기 |
| `A4 4×6 (45×45)` | 대응 제품 미확인(Avery L7121은 45×45 4×**5**) | 확인 전까지 사용자 정의 예시로 |
| 롤 `50×30`, `40×20`… | 폼텍 롤 25종과 겹침 | 폼텍 롤 목록으로 확장, 감열/열전사 구분은 메타데이터로 |

### 8.3 프리셋 UI

- 1단계: 종류(A4 시트 / Letter 시트 / 롤 / 테이프) → 2단계: 제조사 → 3단계: 코드 검색("3108", "V3230", "L7163", "99.1×38.1", "14칸" 모두 검색되게).
- 코드 검색 결과에 `equivalents`를 같이 보여 준다("동일 규격: 프린텍 V3230, Avery L7163").
- `confidence`가 medium/low인 프리셋은 "첫 출력 전 보정 페이지로 확인" 배지를 단다.
- 보정 페이지: 각 라벨 칸의 외곽선과 중심 십자, 좌상단·우하단 칸에 1 mm 눈금자를 그려 사용자가 실제 라벨과 겹쳐 보고 offset/scale을 입력하게 한다.

## 9. 데이터 파일과 재생성 방법

[label-stock-specs.json](label-stock-specs.json)에 시트 라벨 전체가 들어 있다(롤·테이프는 이 문서 §5 표만 있음).
앱의 "새로 만들기 → 기성 라벨 용지" 탭은 이 JSON에서 `npm run stock`으로 만든 [src/model/stockData.ts](../src/model/stockData.ts)를 쓴다. 롤 목록은 [src/model/stock.ts](../src/model/stock.ts)에 직접 적혀 있다. JSON을 고치면 `npm run stock`을 다시 실행한다.

```jsonc
{
  "id": "printec-v3230", "vendor": "Printec", "code": "V3230", "category": "우편발송라벨",
  "kind": "sheet",
  "page":  { "w": 210, "h": 297 },
  "label": { "w": 99.06, "h": 38.1, "shape": "rect", "cornerRadius": null },
  "grid":  { "cols": 2, "rows": 7, "left": 5.08, "top": 15.87, "pitchX": 101.6, "pitchY": 38.1,
             "gapX": 2.54, "gapY": 0, "right": 4.26, "bottom": 14.43 },
  "count": 14, "source": "word-builtin", "confidence": "high",
  "alternatives": [ { "source": "vendor-template", "left": 4.99, "top": 15.49, "pitchX": 101.55, "pitchY": 38.1 } ],
  "equivalents": [ "Avery L7163", "Formtec 3108", "Printec V3810", "..." ],
  "notes": [ "..." ]   // 있을 때만. 비대칭 여백·가장자리 경고·수동 확인 사항
}
```

- `Paper` 변환: `width=page.w, height=page.h, labelWidth=label.w, labelHeight=label.h, cols, rows, marginLeft=grid.left, marginTop=grid.top, gapX=grid.gapX, gapY=grid.gapY, cornerRadius=label.cornerRadius ?? 정책값(§3)`.
- Avery L7169 등 Word가 **가로 용지**로 정의한 항목은 `page.w > page.h`다. 그대로 쓰면 된다.
- 추출 방법(재현용): Windows + Microsoft Word가 있는 PC에서 Word COM `Application.MailingLabel.CreateNewDocument("<라벨명>")`로 라벨 문서를 만들고, `PageSetup.TopMargin/LeftMargin`과 표의 열 폭·행 높이를 읽었다(1 pt = 25.4/72 mm). 제조사 서식(.doc)은 같은 방식으로 파일을 열어 읽었다. 이름 형식: 프린텍·Avery A4·Zweckform은 코드만(`V3230`, `L7163`, `3474`), Avery US는 `"5160 Address Labels"`처럼 설명 포함, A-ONE은 `"A-ONE 72212"`. 폼텍은 Word DB에 없다.
